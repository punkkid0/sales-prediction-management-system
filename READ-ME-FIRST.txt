Sales Prediction Management System
=================================

FOR HIM (easy Windows setup)
----------------------------

1) Install / prepare (ONCE)
   Double-click:  1-SETUP.bat
   - Wait until it finishes (can take several minutes)
   - If it installs Python/XAMPP, allow admin prompts
   - For public links later: create free ngrok account and save authtoken
     when the setup (or 3-START-NGROK) asks

2) Every time you want to use the app
   Double-click:  2-START-SERVERS.bat
   Then open:     http://localhost/spms/

3) Optional - share a PUBLIC link (PC must stay on)
   Double-click:  3-START-NGROK.bat
   Keep that window open
   Open http://127.0.0.1:4040 and copy the HTTPS URL
   Send him:  https://xxxxx.ngrok-free.app/spms/

4) When finished
   Double-click:  STOP-SERVERS.bat

Notes
-----
- Forecasts need Flask. 2-START-SERVERS.bat starts it.
  If Forecasts says the engine is offline, wait about 10 seconds and refresh.
- This project uses MySQL inside XAMPP. Do NOT install PostgreSQL.
- Free ngrok URL can change each time you start it.
